## <img src="https://media.giphy.com/media/WFZvB7VIXBgiz3oDXE/giphy.gif" width="30"> About Me

I'm a **2nd-year Computer Science & Engineering student** at Anil Neerukonda Institute of Technology & Sciences (ANITS), focused entirely on becoming an **AI/ML Engineer**, built on a rigorous foundation of core Computer Science and programming fundamentals.

My learning path is deliberate and sequential: **Programming → Data Structures & Algorithms → SQL/DBMS → NumPy/Pandas → Statistics → Machine Learning → Deep Learning → AI/ML Engineering.** I learn by building, breaking things, understanding why they work, and iterating — not by consuming theory passively.

Most recently, I built an **asynchronous, LLM-integrated data-intelligence pipeline** (FrontierAtlas) — combining async scraping, a multi-provider LLM fallback chain, and entity resolution to turn messy real-world data into structured, validated records. It's the clearest evidence yet of where my engineering is headed: AI-adjacent systems, not just scripts.

I've also picked up full-stack development (React, TypeScript, Node.js, PostgreSQL, Redis, Docker) — primarily through **hackathon-driven, hands-on builds** rather than as a separate career track. It's a supporting skill that lets me eventually ship the intelligent systems I build end-to-end, not the destination itself.

<summary><b>🌐 FRONTIERATLAS — Async LLM-Integrated Data Intelligence Pipeline</b></summary>
<br/>

An asynchronous, fault-tolerant data-ingestion pipeline that scrapes startups, products, research papers, jobs, and news from public sources, then structures the raw data using a multi-tier LLM extraction engine with deterministic entity resolution.

| | |
|---|---|
| **Stack** | Python · asyncio · aiohttp · Pydantic · SQLite · Gemini · Groq · DeepSeek |
| **LLM Reliability** | Multi-provider fallback chain (Gemini → Groq → DeepSeek) with chunking, retries, and exponential backoff for `429`/`413` errors |
| **Data Quality** | Pydantic schema validation, source-traceable records, deterministic entity resolution with an auditable mapping log |
| **Scale** | Validated run acquired 6,000+ startup, 1,000+ product, and 1,000+ research paper records across six exportable tabs |
| **Repository** | [FrontierAtlas Ingestion Pipeline →](https://github.com/sathvikvarma-16/frontieratlas-ingestion-pipeline) |
| **Data Output** | [Google Sheets →](https://docs.google.com/spreadsheets/d/1GkZ0vXzD2jHSD-GRabk11k6qJ1pk2tjSZtmHIR8vVjM/edit?usp=sharing) |

Built with asyncio/aiohttp for concurrent, bounded scraping across heterogeneous sources; every record retains its source URL and unknown fields are left `null` rather than guessed.

</details>
